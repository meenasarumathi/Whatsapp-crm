# Inbox

The shared WhatsApp inbox where your team reads and replies to every customer conversation.

The Inbox has three panels: the **conversation list** (left), the **message thread** (middle) and the **contact panel** (right). On a phone you see one panel at a time — use **Back to conversations** to return to the list.

> **Tip:** If you see "WhatsApp is not connected", an admin must finish Settings → WhatsApp first.

## 1. Conversation list

- **Search conversations...** — find a chat by name, number or text.
- **Status filters** — **All**, **Unread**, **Open**, **Pending**, **Closed**.
- **Tags** filter — show only chats whose contact has the chosen tags.
- **Company** filter — show only chats from one company (**All companies** to reset).
- **Clear all** — removes every filter.

Each row shows the contact name, the last message, the time and an unread marker.

## 2. Message thread

### Header controls

- **Status** — set the chat to **Open** (needs action), **Pending** (waiting on the customer or a teammate) or **Closed** (done).
- **Assign** — give the chat to a teammate (or yourself, shown as "(me)"). **Unassign** clears it. The assignee gets a notification.
- **Refresh** — reload the conversation.
- **Show / Hide contact panel** — toggles the right-hand panel.

### The 24-hour session window

WhatsApp only lets you send free-form messages within **24 hours of the customer's last message**. The timer in the thread shows the time left (e.g. "5h remaining").

- While the window is open you can type anything.
- When it says **Expired**, the box shows "Session expired – use a template". You must send an approved **template** to restart the chat.
- A brand-new chat with no customer message also needs a template ("Send a template to start the conversation").

### Writing and sending (the composer)

- Type in the box. **Enter** sends; **Shift+Enter** adds a new line.
- **Attach media** (paperclip) → **Photo**, **Video** or **Document**. Add a caption before sending.
- **Voice note** (microphone) → record, then **Stop and attach** or **Cancel**.
- **Templates** → pick an approved template, fill in its placeholders, check the **Preview**, then **Send template**.
- **More** menu:
  - **Quick replies** — insert a saved snippet.
  - **Interactive message** — send tappable **Reply buttons** (up to 3) or a **List** menu.
  - **Save as quick reply** — saves what you typed for reuse.
- **✨ Draft with AI** — the AI writes a suggested reply into the box; edit it before sending. (Needs AI set up under AI Agents → Setup.)

### Actions on a message

Hover (or long-press) a message for:

- **Reply** — quote that message in your answer (**Cancel reply** to undo).
- **React** — add an emoji reaction.
- **Copy text** — copy the message text.
- **Delete** — remove your own message.

Click a photo or video to open the media viewer (zoom, next/previous, **Download**, **Open original**). Messages that failed show **Not delivered**. Messages sent by the AI carry an **AI** badge.

### AI banner

If the AI assistant is handling a chat you will see "AI assistant is replying automatically". Click **Take over** to stop the bot and reply yourself; click **Resume AI** to hand it back.

## 3. Contact panel

The panel on the right has two tabs at the top: **Details** and **Data sheet**.

**Details**

- **Contact info** — name, phone, email, company.
- **Tags** — the contact's tags.
- **Notes** — internal notes only your team sees ("Add a note...").
- **Deals** — deals linked to this contact.

**Data sheet** — share a conversation as a spreadsheet, or open one someone shared with you:

- **Download Excel (.xlsx)** — every message in this chat with date, time, sender (Customer / Agent / Bot / AI), type, message, status, template and media link, plus a "Contact" sheet.
- **Download CSV** — the same, as a CSV file.
- **Upload Excel / CSV** — opens a conversation file in a preview. The file needs a **Message** column; **From**, **Date** and **Time** are used when present. From the preview you can:
  - **Save to contact notes** — keeps the whole transcript as a note on this contact.
  - **Teach AI** — every customer question and the reply after it becomes a Q&A answer in **Train AI**.

> **Tip:** Nothing in the Data sheet tab sends a WhatsApp message.

## Typical inbox workflow

1. Open **Unread** to see new messages.
2. Open a chat, read it, and **Assign** it to the right person (or yourself).
3. Reply — use a **quick reply** or **Draft with AI** to go faster.
4. Add a **tag** or **note**, and create a **deal** in Pipelines if it is a sales lead.
5. Set the status to **Pending** while waiting on the customer, and **Closed** when finished.
