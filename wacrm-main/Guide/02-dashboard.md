# Dashboard

The home page: live numbers, charts and recent activity across conversations, contacts, deals, broadcasts and automations.

Open it from **Dashboard** in the sidebar, or by clicking the logo at the top-left.

## Metric cards (top row)

| Card | What it shows |
| --- | --- |
| **Active Conversations** | Conversations currently open. |
| **New Contacts Today** | Contacts created today, compared with yesterday. |
| **Open Deals Value** | Total value of deals not yet won or lost, with the number of open deals. |
| **Messages Sent Today** | Outgoing messages today, compared with yesterday. |

Each card shows a small up/down change versus yesterday ("No change" if equal).

## Quick actions

Shortcut buttons to start common work:

- **New Contact** → opens Contacts.
- **New Deal** → opens Pipelines.
- **New Broadcast** → opens the broadcast wizard.
- **New Automation** → opens the automation builder.

## Charts

- **Conversations Over Time** — daily message volume split into **Incoming** and **Outgoing**. Use the range selector (e.g. 7 / 30 days) to change the period. Hover a bar for exact counts.
- **Pipeline Value** — a donut of open deals by stage, with the **Total** in the middle.
- **Average First Response Time** — minutes taken to reply to a customer's first unanswered message, by weekday. It compares **This week** with **Last week** against a target line.

## Recent Activity

A live feed of what happened: messages, deal changes, broadcasts and automation runs, with times like "5m ago". Use **Show** to load more, or **View all →** for the full list.

> **Tip:** A brand-new account shows "Not enough data yet". The charts fill in as soon as you start sending and receiving messages and creating deals.
