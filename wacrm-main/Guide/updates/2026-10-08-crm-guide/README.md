# New: in-app Guide

A complete user guide is now built into the CRM under **Guide** in the sidebar.

## What changed

- A new **Guide** option in the left sidebar, between AI Agents and Settings.
- One chapter for every tab: Getting started, Dashboard, Inbox, Notifications, Contacts, Pipelines, Broadcasts, Automations, Flows, AI Agents and Settings.
- An **End-to-end workflows** chapter showing how the tabs work together.
- A **FAQ & troubleshooting** chapter.
- This **What's new** section, which lists every future change to the CRM.

## Who it affects

- Roles: everyone (Owner, Admin, Agent, Viewer).

## How to use it

1. Click **Guide** in the sidebar.
2. New users: start with **Getting started** and follow the day-one checklist.
3. Use the chapter list on the left to jump to any tab's instructions.
4. Check **What's new** after each update to the CRM.
