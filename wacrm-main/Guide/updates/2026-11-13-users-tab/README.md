# Users tab in the sidebar

User management now has its own **Users** tab in the left sidebar, between Wallet and Settings.

## What changed

- New **Users** tab (bottom of the sidebar, between **Wallet** and **Settings**).
- It opens the same user list as Settings → Subscription users: roles, trials, tab access, notes and temporary passwords.
- Only Super admin, Admin 1 and Admin 2 see the tab.

## Who it affects

- Roles: Super admin, Admin 1, Admin 2
- Tabs: Users (new), Settings → Subscription users (unchanged)

## How to use it

1. Click **Users** in the left sidebar.
2. Search or filter the list, click a user to open their settings.
