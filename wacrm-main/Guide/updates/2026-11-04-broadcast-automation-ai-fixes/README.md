# Broadcast templates, automation tags and AI status fixes

New broadcasts can now pull your approved templates from Meta, automations no longer stop at "tag is required", and Train AI says why AI features are off.

## What changed

- Broadcasts → New Broadcast, step 1: **Sync from Meta** and **Create template** buttons when no approved template exists, plus a list of templates waiting for approval.
- Automations: the **Add Tag**, **Remove Tag** and **Tag Added** pickers have a **New tag** option, so an account with no tags can finish the Welcome Message quick-start.
- Train AI → What AI can do: a notice when the first five AI features are off because no AI provider key is connected or the assistant is switched off.

## Who it affects

- Roles: Owner / Admin / Agent
- Tabs: Broadcasts, Automations, Train AI

## How to use it

1. Broadcasts → New Broadcast → **Sync from Meta**, then pick a template.
2. Automations → Welcome Message → open **Add Tag** → **New tag** → type a name → **Create**.
3. Train AI → What AI can do → **Add API key** if the notice is shown.
